Use this page to check what Youverify supports in a given country before you build. Coverage varies by product: **Liveness** works globally, **Document Capture** supports the countries and document types listed below, and each **identity (KYC)** and **business (KYB)** verification endpoint supports specific countries.

## Coverage at a glance

| Product | Coverage |
| --- | --- |
| **Liveness** | Global. No country limitations. |
| **Document Capture** | 119 countries and territories across six regions. See [Document Capture](#document-capture) for the document types accepted in each. |
| **Identity verification (KYC)** | Country-specific endpoints for Nigeria, South Africa, Kenya, Ghana and Côte d'Ivoire, plus Global ID Validation. See [Identity verification](#identity-verification-kyc). |
| **Business verification (KYB)** | Country-specific endpoints for Nigeria, South Africa and Côte d'Ivoire, plus global company search. See [Business verification](#business-verification-kyb). |
| **AML screening** | Not tied to a single country. Screening endpoints accept a country filter. PEP+ covers Nigerian domestic PEPs. See [AML screening](#aml-screening). |
| **Address verification** | Nigeria. See [Address verification](#address-verification). |

## Liveness

Liveness detection is a global product with no country limitations. It is not restricted to any country or region. See the [SDKs](/sdks/overview) for integration guides.

## Identity verification (KYC)

Identity verification endpoints are organised by country. Use the country-specific endpoint (or the `idType` field on Verify Entity (KYC)) for the country your customer is from.

| Country | Verifications available |
| --- | --- |
| **Nigeria** | BVN, BVN Premium, NIN, Driver's License, Phone Number, Advanced Phone Search (NIN holder by phone), Individual Tax ID, Individual Credit Report, Basic and Premium Bank Account Verification |
| **South Africa** | South African ID Number (SAID), Phone Number, Bank Account Verification, Proof of Address |
| **Kenya** | National ID, Alien ID, International Passport, Driver's License, Identity Number, Tax PIN, KRA PIN, Phone Number, Address, Plate Number, Collateral ID, Bank Account Verification (and Bank List), Credit History, Employment History |
| **Ghana** | International Passport, SSNIT, Voter's Card |
| **Côte d'Ivoire** | National ID, Old National ID, Residence Card |
| **Other countries** | Global ID Validation compares an ID and personal details against government, authoritative and commercial data sources. Pass the country as an ISO 3166-1 alpha-2 `countryCode`. The advanced search option is not available in every country. |

Facial Comparison is not tied to a country. It compares two images and works for any customer.

## Business verification (KYB)

| Scope | Verifications available |
| --- | --- |
| **Nigeria** | KYB Basic, Business Tax ID, Business TIN, TaxID and Business Verification, Business Address Verification |
| **South Africa** | Business Account Verification, Business Address Verification |
| **Côte d'Ivoire** | Company Filings |
| **Global** | Search for Businesses by name with optional country filter, Retrieve Business Details, KYB Bulk Upload, and Premium Company Search. Premium checks are available for Nigeria, South Africa and Kenya. |

To get the live list of countries and sub-divisions supported for KYB checks, call the Get Supported Countries and Regions endpoint (`GET /v2/api/verifications/global/supported-countries-and-region`). When using sub-divisions in a company search, use the sub-division code rather than the main country code.

## AML screening

The API reference does not restrict AML screening to specific countries. PEP, sanctions, adverse media and crypto screening endpoints accept an optional country filter to narrow results. PEP+ Search is specific to Nigerian domestic politically exposed persons.

## Address verification

Physical address verification (individuals, guarantors and businesses) is currently built around Nigerian addresses and states. The Digital Address Verification Service verifies an address using the candidate's most recent utility purchase, matched by phone number.
