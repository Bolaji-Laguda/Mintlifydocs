The Document Capture SDK lets users photograph a government-issued ID, such as a passport, national ID card, driver's licence or residence permit, from within your app. The captured image is submitted for extraction and verification.

## Before you integrate

Generate a session ID from your backend with your secret API key. See [Session tokens](/sdks/liveness-sdk).

<Warning>
  Never embed your secret API key in a web page or mobile app. Generate the session ID server-side and pass only that value to the SDK.
</Warning>
