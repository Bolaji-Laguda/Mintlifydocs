Use the Youverify Web SDK to let users capture an identity document from inside your web application. The SDK opens a modal, guides the user through capturing the document, and returns the extracted details to your page.

## Before you start

You need your **Public Merchant Key**. You can find it in the **API / Webhook** section of your Youverify dashboard. It is safe to use in client-side code.

<Info>
  Document Capture on web is initialized with your Public Merchant Key. You don't need to generate a session ID on your server for this flow. Keep your secret API key on your server and never put it in a web page.
</Info>

## Installation

<Tabs>
  <Tab title="npm">
    ```bash
    npm install youverify-web-sdk
    ```
  </Tab>
  <Tab title="yarn">
    ```bash
    yarn add youverify-web-sdk
    ```
  </Tab>
</Tabs>

## Integration steps

<Steps>
  <Step title="Create the Document Capture module">
    Pass your options to `YouverifySDK.documentCapture`:

    ```javascript
    const documentCaptureModule = new YouverifySDK.documentCapture({
      publicMerchantKey: 'YOUR_PUBLIC_MERCHANT_KEY',
      sandboxEnvironment: true, // set to false in production
    
      personalInformation: {
        firstName: 'John',
      },
    
      // Optional: customize the greeting, button text and colours
      appearance: {
        greeting: 'We will need to capture your document. It will only take a moment.',
        actionText: 'Capture Document',
        buttonBackgroundColor: '#46B2C8',
        buttonTextColor: '#ffffff',
        primaryColor: '#46B2C8',
      },
    
      // Optional: restrict the countries and document types
      countries: [
        {
          countryCode: 'ng',
          idTypes: ['passport', 'Residence Permit', 'Driving License', 'NIN'],
        },
      ],
    
      onSuccess: (data) => {
        // The user captured the document and you received the result
      },
      onFailure: (error) => {
        // The result could not be retrieved
      },
      onClose: () => {
        // The user closed the modal
      },
    });
    ```
  </Step>
  <Step title="Initialize the module">
    Call `initialize()` once. It throws if the options are invalid, so wrap it in a `try` block.

    ```javascript
    try {
      documentCaptureModule.initialize();
    } catch (error) {
      // Handle the validation error
    }
    ```
  </Step>
  <Step title="Start the capture flow">
    Call `start()` when your user is ready, for example on a button click. This opens the modal.

    ```javascript
    documentCaptureModule.start();
    ```
  </Step>
</Steps>

## Options

<ParamField body="publicMerchantKey" type="string" required>
  Your Public Merchant Key from the **API / Webhook** section of your dashboard.
</ParamField>

<ParamField body="sandboxEnvironment" default="false" type="boolean">
  Set to `true` to run in sandbox mode while you develop and test. Set to `false` for production.
</ParamField>

<ParamField body="hideUsingSecondaryDevice" default="false" type="boolean">
  Set to `true` to hide the option to capture the document with a secondary device.
</ParamField>

<ParamField body="personalInformation" type="object">
  User attributes used to personalize the experience.

  <Expandable title="properties">
    <ParamField body="firstName" type="string">
      The user's first name.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="appearance" type="object">
  Customize the greeting text, button text and colours. All fields are optional.

  <Expandable title="properties">
    <ParamField body="greeting" type="string">
      The text shown to the user before capture starts.
    </ParamField>

    <ParamField body="actionText" type="string">
      The label of the button that starts the capture.
    </ParamField>

    <ParamField body="buttonBackgroundColor" type="string">
      Button background colour as a hex value, for example `#46B2C8`.
    </ParamField>

    <ParamField body="buttonTextColor" type="string">
      Button text colour as a hex value, for example `#ffffff`.
    </ParamField>

    <ParamField body="primaryColor" type="string">
      The main accent colour of the modal.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="countries" type="array">
  Limit the capture to specific countries and document types. Each item is an object. All fields are optional.

  <Expandable title="properties">
    <ParamField body="countryCode" type="string">
      The country the document should be captured for, for example `ng` or `CA`.
    </ParamField>

    <ParamField body="idTypes" type="string[]">
      The document types to offer in that country, for example `["passport", "Driving License"]`.
    </ParamField>

    <ParamField body="province" type="string[]">
      The province or state within the country. Leave it out if the country has no provinces.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="metadata" type="object">
  Any other information you want sent to your webhook URL. Use your own keys.
</ParamField>

<ParamField body="onSuccess" type="(data) => void">
  Called when document capture has a result. See [Success result](#success-result).
</ParamField>

<ParamField body="onFailure" type="(error) => void">
  Called when the result could not be retrieved. Receives an error object.
</ParamField>

<ParamField body="onClose" type="() => void">
  Called when the modal is closed.
</ParamField>

<Tip>
  To see which countries, provinces and document types are supported, see [Country and product coverage](/resources/coverage#document-capture).
</Tip>

## Success result

When capture succeeds, `onSuccess` receives an object like this:

```javascript
{
  documentNumber: 'xyz',
  firstName: 'John',
  lastName: 'Doe',
  fullName: 'John Doe',
  dateOfBirth: '29-01-2022',
  dateOfExpiry: '29-01-2022',
  gender: 'M',
  rawMRZString: '*****...',
  fullDocumentFrontImage: '', // base64 image of the document's front
  fullDocumentBackImage: '',  // base64 image of the document's back
  fullDocumentImage: ''       // base64 image of the front, when there is no back to capture
}
```

<ResponseField name="fullDocumentFrontImage" type="string">
  Base64 image of the front of the document.
</ResponseField>

<ResponseField name="fullDocumentBackImage" type="string">
  Base64 image of the back of the document.
</ResponseField>

<ResponseField name="fullDocumentImage" type="string">
  Base64 image of the front of the document. Present when the document has no back to capture.
</ResponseField>

<Warning>
  The result contains personal data and document images. Send it to your backend over HTTPS and don't write it to logs or store it in the browser.
</Warning>

If you don't pass an `onSuccess` callback, nothing happens when capture succeeds.

## Close the modal from code

You can close the SDK modal from your own code with `setShowModal`. It takes a Boolean and returns nothing.

| Method | Parameters | Returns | Description |
| --- | --- | --- | --- |
| `setShowModal` | Boolean | None | Closes the SDK modal from code. |

## Use it in a mobile app

There is no native mobile SDK for Document Capture yet. To offer it in an Android or iOS app, you can wrap this web integration in a WebView. See [Use Document Capture in a mobile app](/sdks/document-capture/mobile-webview).
