Address verification results can be downloaded as a PDF proof-of-address certificate. Each certificate shows one of these statuses.

<Frame>
  <img src="/images/how-to/address-report-statuses/report.png" alt="Printable address verification report showing a status" />
</Frame>

| Status | What it means |
| --- | --- |
| **Verified** (also shown as Confirmed) | A field agent confirmed the residence and took a geotagged photo. |
| **Unverified** (also shown as Mismatch) | The address could not be confirmed, or the candidate had moved. |
| **Pending Visit** | The request is assigned to a field officer. |
| **Rejected** | The address details were not enough, or the landmark was not valid. |

If a request is rejected, submit it again with a complete address and a clear landmark. See [Submit an address verification request](/how-to/address-verification).
