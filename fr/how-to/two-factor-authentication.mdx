L'authentification à deux facteurs (2FA) demande un code à usage unique issu d'une application d'authentification à chaque connexion à Cowork, en plus de votre mot de passe.

Un administrateur peut également imposer la 2FA à tous les utilisateurs de l'organisation. Lorsque cette option est activée, chaque utilisateur doit configurer la 2FA et ne peut pas l'ignorer.

## Activer la 2FA

<Steps>
  <Step title="Ouvrir Account Settings">
    Connectez-vous à Cowork. Cliquez sur votre **Profile icon**, puis sélectionnez **Account Settings**.

    <Frame>
      <img
        src="/images/how-to/two-factor-authentication/step-1.png"
        alt="Account Settings ouvert depuis le menu du profil"
      />
    </Frame>
  </Step>
  <Step title="Ouvrir System Settings">
    Cliquez sur **System Settings**.
  </Step>
  <Step title="Activer la 2FA pour la connexion">
    Activez l'interrupteur pour activer la 2FA à la connexion, puis cliquez sur **Activate 2FA**.

    <Frame>
      <img
        src="/images/how-to/two-factor-authentication/step-3.png"
        alt="Interrupteur d'activation de la 2FA pour la connexion et bouton Activate 2FA"
      />
    </Frame>
  </Step>
  <Step title="Associer votre application d'authentification">
    Scannez le code QR affiché à l'écran avec votre application d'authentification. Si vous ne pouvez pas le scanner, saisissez plutôt la clé de configuration dans l'application.

    <Frame>
      <img
        src="/images/how-to/two-factor-authentication/step-4.png"
        alt="Code QR et clé de configuration affichés pour l'enregistrement de l'application d'authentification"
      />
    </Frame>
  </Step>
  <Step title="Confirmer avec un code à usage unique">
    Saisissez dans Cowork le code à usage unique de votre application d'authentification pour terminer l'enregistrement.
  </Step>
  <Step title="Conserver vos codes de récupération">
    Si Cowork affiche des codes de récupération, conservez-les en lieu sûr. Vous pourriez en avoir besoin si vous perdez l'accès à votre application d'authentification.
  </Step>
</Steps>

<Warning>
  Saisissez la clé de configuration uniquement dans votre application d'authentification. Ne la communiquez jamais, ni vos codes à usage unique, à qui que ce soit.
</Warning>
