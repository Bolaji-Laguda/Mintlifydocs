Les entités sont les personnes et les entreprises avec lesquelles vous travaillez. Chaque entité dispose d'un profil avec son score de risque, ses vérifications associées et son activité de dépistage, afin que vous puissiez surveiller le risque dans le temps. Consultez [Entity 360](/fr/concepts/entity-360) pour en savoir plus.

Il existe trois types d'entités : **Individual**, **Business** et **UBOs** (bénéficiaires effectifs).

## Créer une entité

<Steps>
  <Step title="Ouvrir Entities">
    Cliquez sur **Entities** dans la barre latérale gauche.

    <Frame>
      <img
        src="/images/how-to/manage-entities/step-1.png"
        alt="Entities dans la barre latérale gauche"
      />
    </Frame>
  </Step>
  <Step title="Choisir le type d'entité">
    Sélectionnez l'onglet **Individual**, **Business** ou **UBOs**.
  </Step>
  <Step title="Lancer une nouvelle demande">
    Cliquez sur **New Request** en haut à droite.

    <Frame>
      <img
        src="/images/how-to/manage-entities/step-3.png"
        alt="Bouton New Request sur la page Entities"
      />
    </Frame>
  </Step>
  <Step title="Renseigner le profil">
    Remplissez les champs obligatoires du profil. Les champs habituels comprennent le nom, le numéro d'immatriculation, la date de naissance, le type de pièce d'identité, le numéro d'identification fiscale et le pourcentage de détention, selon le type d'entité.
  </Step>
  <Step title="Attribuer les paramètres de risque et enregistrer">
    Attribuez les paramètres de risque, puis cliquez sur **Save Entity**.
  </Step>
</Steps>

## Consulter et gérer une entité

Ouvrez n'importe quelle entité pour afficher ses détails dans le panneau latéral : son score de risque, ses vérifications associées et son activité de dépistage.

<Frame>
  <img
    src="/images/how-to/manage-entities/drawer.png"
    alt="Panneau d'entité affichant le score de risque, les vérifications associées et l'activité de dépistage"
  />
</Frame>

Pour savoir comment les scores sont calculés, consultez [Risk scoring](/fr/concepts/risk-scoring).
