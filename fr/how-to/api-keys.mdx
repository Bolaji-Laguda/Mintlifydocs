Les clés API authentifient vos appels de serveur à serveur vers Youverify. Créez des clés distinctes pour les environnements Sandbox et Live.

## Créer une clé API

<Steps>
  <Step title="Ouvrir le Developer Hub">
    Cliquez sur **Developer Hub** dans la barre latérale.

    <Frame>
      <img
        src="/images/how-to/api-keys/step-1.png"
        alt="Developer Hub dans la barre latérale de Cowork"
      />
    </Frame>
  </Step>
  <Step title="Choisir l'environnement">
    Choisissez **Sandbox** ou **Live**.
  </Step>
  <Step title="Créer une nouvelle clé">
    Cliquez sur **\+ Create New API Key**.

    <Frame>
      <img
        src="/images/how-to/api-keys/step-3.png"
        alt="Bouton Create New API Key dans le Developer Hub"
      />
    </Frame>
  </Step>
  <Step title="Nommer la clé et définir les autorisations">
    Saisissez un nom pour la clé et définissez ses autorisations ou ses périmètres (scopes).
  </Step>
  <Step title="Copier et stocker la clé secrète">
    Copiez la clé secrète et conservez-la de manière sécurisée.

    <Frame>
      <img
        src="/images/how-to/api-keys/step-5.png"
        alt="Clé secrète nouvellement créée avec un bouton de copie"
      />
    </Frame>
  </Step>
</Steps>

<Warning>
  Conservez votre clé secrète sur votre serveur. Ne la placez jamais dans une page web, une application mobile ou un système de contrôle de version.
</Warning>

Pour savoir comment utiliser la clé dans vos requêtes, consultez [Authentification](/fr/get-started/authentication).
