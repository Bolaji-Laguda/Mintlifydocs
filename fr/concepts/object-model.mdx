Cette page décrira comment les principaux objets Youverify sont liés entre eux.

## Sections prévues

- **Entité :** le dossier du client ou de l'entreprise. Voir [Entity 360](/fr/concepts/entity-360).
- **Vérification :** un contrôle KYC, KYB ou AML exécuté sur une entité.
- **Alerte :** un signal généré par la surveillance. Voir le [Modèle de surveillance](/fr/concepts/monitoring-model).
- **Dossier :** un regroupement d'alertes en vue d'une investigation.
- **Rapport :** un document réglementaire ou interne construit à partir des éléments ci-dessus.

- Le cycle de vie et les valeurs de statut de chaque objet
