---

Lorsqu'un client fournit une pièce d'identité officielle (BVN, NIN, carte d'identité nationale ou passeport), vous pouvez vérifier son identité directement auprès de la source faisant autorité et intégrer le résultat à son dossier d'entité. Il s'agit du parcours d'intégration offrant le plus haut niveau de confiance : les champs de données personnelles renvoyés proviennent du registre officiel, et une discordance sur le nom ou la date de naissance déclenche automatiquement un signal de fraude.

Ce guide vous accompagne dans la création d'une entité, le déclenchement d'un contrôle KYC avec un numéro de pièce d'identité, l'interprétation du résultat et la compréhension de la mise à jour du score de risque.

## Prérequis

- Un compte Youverify sur [cowork.youverify.co](https://cowork.youverify.co)
- Votre clé secrète d'API, disponible dans le tableau de bord sous **Settings → API Keys**
- Le type de pièce d'identité, le numéro de pièce et le pays du client

  ### Déclencher la vérification KYC avec la pièce d'identité officielle

Transmettez le nom et la date de naissance du client dans le bloc `validations` afin de recouper les données fournies avec celles renvoyées par le registre : une discordance déclenche un signal de fraude automatique.

  Les exemples ci-dessous couvrent les types de pièces d'identité les plus courants. Sélectionnez votre pays :

  ### Examiner le résultat de la vérification

  Une vérification réussie renvoie `"status": "found"` avec les champs de données personnelles récupérés depuis le registre faisant autorité. Comparez le nom et la date de naissance renvoyés avec ceux que vous détenez dans vos dossiers.

  ```json Response — match found
  {
    "success": true,
    "status_code": 200,
    "message": "Identity check successful!",
    "data": {
      "id": "ent_684f5cc5a47a3926763b83a7",
      "entity": {
        "entityId": "ent_684f5cc5a47a3926763b83a7",
        "isNew": false,
        "message": ""
      },
      "identityCheck": {
        "status": "found",
        "firstName": "Jane",
        "lastName": "Doe",
        "dateOfBirth": "1990-06-15",
        "middleName": "Adaeze",
        "phone": "08012345678",
        "gender": "Female",
        "type": "bvn",
        "nationality": "NG",
        "idNumber": "22222222222",
        "isExpired": false,
        "verificationId": "69da8ae76398f3a575c950e0"
      }
    },
    "links": []
  }
  ```

  Si la pièce d'identité est introuvable dans le registre, `"status"` renvoie `"not_found"`. Si le nom ou la date de naissance fournis dans `validations` ne correspondent pas à l'enregistrement du registre, Youverify déclenche automatiquement un signal de fraude sur l'entité.

  <Warning>
    Un résultat `"not_found"` ne signifie pas nécessairement que le client est frauduleux : la pièce d'identité peut être récente ou le registre temporairement indisponible. Examinez l'historique des signaux de l'entité avant de prendre une décision.
  </Warning>

  ### Vérifier le score de risque mis à jour de l'entité

  Une fois la vérification KYC terminée, le score de risque de l'entité est réévalué en tenant compte du résultat de la vérification. Récupérez l'entité pour lire le score mis à jour :


## Ce qui se passe en coulisses

Lorsque vous soumettez la vérification KYC, Youverify :

1. Interroge la source faisant autorité (par exemple la base de données BVN du Nigeria, la NIMC pour le NIN)
2. Compare les données personnelles renvoyées avec le bloc `validations` que vous avez fourni
3. Rattache le résultat au journal d'activité et au dossier 360 de l'entité
4. Recalcule le score de risque en intégrant le contrôle AML, le statut de correspondance d'identité et les éventuels signaux de fraude

Tout cela est automatique. Le résultat est conservé sur le dossier de l'entité et non dans un rapport autonome distinct.
