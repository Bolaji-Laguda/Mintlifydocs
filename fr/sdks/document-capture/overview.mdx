Le SDK de capture de documents permet aux utilisateurs de photographier une pièce d'identité officielle, comme un passeport, une carte d'identité nationale, un permis de conduire ou un titre de séjour, depuis votre application. L'image capturée est soumise pour extraction et vérification.

## Avant d'intégrer

Générez un identifiant de session depuis votre backend avec votre clé API secrète. Consultez [Jetons de session](/fr/sdks/liveness-sdk).

<Warning>
  N'intégrez jamais votre clé API secrète dans une page web ou une application mobile. Générez l'identifiant de session côté serveur et ne transmettez au SDK que cette valeur.
</Warning>
