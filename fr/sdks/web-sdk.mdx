title: "Intégrer la capture de documents sur le web"
sidebarTitle: "Intégration web"

---

Utilisez le SDK Web de Youverify pour permettre à vos utilisateurs de capturer une pièce d'identité depuis votre application web. Le SDK ouvre une fenêtre modale, guide l'utilisateur pendant la capture du document, puis renvoie les informations extraites à votre page.

## Avant de commencer

Vous avez besoin de votre **Public Merchant Key** (clé marchand publique). Vous la trouverez dans la section **API / Webhook** de votre tableau de bord Youverify. Elle peut être utilisée sans risque dans du code côté client.

<Info>
  La capture de documents sur le web s'initialise avec votre Public Merchant Key. Vous n'avez pas besoin de générer d'identifiant de session sur votre serveur pour ce parcours. Gardez votre clé d'API secrète sur votre serveur et ne la placez jamais dans une page web.
</Info>

## Étapes d'intégration

<Steps>
  <Step title="Créer le module de capture de documents">
    Transmettez vos options à `YouverifySDK.documentCapture` :

    ```javascript
    const documentCaptureModule = new YouverifySDK.documentCapture({
      publicMerchantKey: 'YOUR_PUBLIC_MERCHANT_KEY',
      sandboxEnvironment: true, // false en production
    
      personalInformation: {
        firstName: 'John',
      },
    
      // Facultatif : personnalisez le message d'accueil, le texte du bouton et les couleurs
      appearance: {
        greeting: 'We will need to capture your document. It will only take a moment.',
        actionText: 'Capture Document',
        buttonBackgroundColor: '#46B2C8',
        buttonTextColor: '#ffffff',
        primaryColor: '#46B2C8',
      },
    
      // Facultatif : limitez les pays et les types de documents
      countries: [
        {
          countryCode: 'ng',
          idTypes: ['passport', 'Residence Permit', 'Driving License', 'NIN'],
        },
      ],
    
      onSuccess: (data) => {
        // L'utilisateur a capturé le document et vous avez reçu le résultat
      },
      onFailure: (error) => {
        // Le résultat n'a pas pu être récupéré
      },
      onClose: () => {
        // L'utilisateur a fermé la fenêtre modale
      },
    });
    ```
  </Step>
  <Step title="Initialiser le module">
    Appelez `initialize()` une seule fois. La méthode lève une erreur si les options sont invalides ; placez-la donc dans un bloc `try`.

    ```javascript
    try {
      documentCaptureModule.initialize();
    } catch (error) {
      // Gérez l'erreur de validation
    }
    ```
  </Step>
  <Step title="Démarrer le parcours de capture">
    Appelez `start()` lorsque votre utilisateur est prêt, par exemple au clic sur un bouton. Cela ouvre la fenêtre modale.

    ```javascript
    documentCaptureModule.start();
    ```
  </Step>
</Steps>

## Options

<ParamField body="publicMerchantKey" type="string" required>
  Votre Public Merchant Key, disponible dans la section **API / Webhook** de votre tableau de bord.
</ParamField>

<ParamField body="sandboxEnvironment" default="false" type="boolean">
  Définissez `true` pour utiliser le mode sandbox pendant le développement et les tests. Définissez `false` pour la production.
</ParamField>

<ParamField body="hideUsingSecondaryDevice" default="false" type="boolean">
  Définissez `true` pour masquer l'option de capture du document avec un second appareil.
</ParamField>

<ParamField body="personalInformation" type="object">
  Attributs de l'utilisateur servant à personnaliser l'expérience.

  <Expandable title="propriétés">
    <ParamField body="firstName" type="string">
      Le prénom de l'utilisateur.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="appearance" type="object">
  Personnalisez le message d'accueil, le texte du bouton et les couleurs. Tous les champs sont facultatifs.

  <Expandable title="propriétés">
    <ParamField body="greeting" type="string">
      Le texte affiché à l'utilisateur avant le début de la capture.
    </ParamField>

    <ParamField body="actionText" type="string">
      Le libellé du bouton qui démarre la capture.
    </ParamField>

    <ParamField body="buttonBackgroundColor" type="string">
      Couleur de fond du bouton, en valeur hexadécimale, par exemple `#46B2C8`.
    </ParamField>

    <ParamField body="buttonTextColor" type="string">
      Couleur du texte du bouton, en valeur hexadécimale, par exemple `#ffffff`.
    </ParamField>

    <ParamField body="primaryColor" type="string">
      La couleur d'accent principale de la fenêtre modale.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="countries" type="array">
  Limitez la capture à certains pays et types de documents. Chaque élément est un objet. Tous les champs sont facultatifs.

  <Expandable title="propriétés">
    <ParamField body="countryCode" type="string">
      Le pays pour lequel le document doit être capturé, par exemple `ng` ou `CA`.
    </ParamField>

    <ParamField body="idTypes" type="string[]">
      Les types de documents proposés dans ce pays, par exemple `["passport", "Driving License"]`.
    </ParamField>

    <ParamField body="province" type="string[]">
      La province ou l'État du pays. Omettez ce champ si le pays n'a pas de provinces.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="metadata" type="object">
  Toute autre information que vous souhaitez envoyer à l'URL de votre webhook. Utilisez vos propres clés.
</ParamField>

<ParamField body="onSuccess" type="(data) => void">
  Appelée lorsque la capture de documents produit un résultat. Consultez [Résultat en cas de succès](#résultat-en-cas-de-succès).
</ParamField>

<ParamField body="onFailure" type="(error) => void">
  Appelée lorsque le résultat n'a pas pu être récupéré. Reçoit un objet d'erreur.
</ParamField>

<ParamField body="onClose" type="() => void">
  Appelée lorsque la fenêtre modale est fermée.
</ParamField>

<Tip>
  Pour connaître les pays, provinces et types de documents pris en charge, consultez [Couverture par pays et par produit](/fr/resources/coverage).
</Tip>

## Résultat en cas de succès

Lorsque la capture réussit, `onSuccess` reçoit un objet de ce type :

```javascript
{
  documentNumber: 'xyz',
  firstName: 'John',
  lastName: 'Doe',
  fullName: 'John Doe',
  dateOfBirth: '29-01-2022',
  dateOfExpiry: '29-01-2022',
  gender: 'M',
  rawMRZString: '*****...',
  fullDocumentFrontImage: '', // image base64 du recto du document
  fullDocumentBackImage: '',  // image base64 du verso du document
  fullDocumentImage: ''       // image base64 du recto, lorsqu'il n'y a pas de verso à capturer
}
```

<ResponseField name="fullDocumentFrontImage" type="string">
  Image base64 du recto du document.
</ResponseField>

<ResponseField name="fullDocumentBackImage" type="string">
  Image base64 du verso du document.
</ResponseField>

<ResponseField name="fullDocumentImage" type="string">
  Image base64 du recto du document. Présente lorsque le document n'a pas de verso à capturer.
</ResponseField>

<Warning>
  Le résultat contient des données personnelles et des images du document. Envoyez-le à votre backend via HTTPS, et ne l'écrivez pas dans les journaux ni ne le stockez dans le navigateur.
</Warning>

Si vous ne transmettez pas de callback `onSuccess`, il ne se passe rien lorsque la capture réussit.

## Fermer la fenêtre modale par le code

Vous pouvez fermer la fenêtre modale du SDK depuis votre propre code avec `setShowModal`. La méthode prend un booléen et ne renvoie rien.

| Méthode | Paramètres | Retour | Description |
| --- | --- | --- | --- |
| `setShowModal` | Booléen | Aucun | Ferme la fenêtre modale du SDK par le code. |

## Utilisation dans une application mobile

Il n'existe pas encore de SDK mobile natif pour la capture de documents. Pour la proposer dans une application Android ou iOS, vous pouvez encapsuler cette intégration web dans une WebView. Consultez [Utiliser la capture de documents dans une application mobile](/fr/sdks/document-capture/mobile-webview).
